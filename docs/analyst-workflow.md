# Analyst Workflow Alignment

PhishTix is not only a user-awareness concept. It is also influenced by the structured thinking used by security analysts when reviewing suspicious communication.

## Workflow Concepts Reflected

- identify the suspicious message
- inspect visible indicators
- evaluate sender context
- assess urgency and requested action
- review links or attachment context carefully
- classify likelihood of phishing risk
- document findings clearly
- support safe next-step decision-making

## Why This Matters

This workflow-based design approach makes the project useful as:
- a cybersecurity portfolio artifact
- a bridge between user education and SOC thinking
- a demonstration of practical security communication

## Portfolio Relevance

For recruiters and educators, this project shows that I am thinking beyond tools alone and focusing on:
- how users experience security problems
- how analysts structure review

- how cybersecurity can be communicated clearly
