# Problem Statement

Phishing attacks continue to succeed because they rely on human trust, urgency, confusion, and impersonation rather than advanced technical exploitation alone.

For many users, suspicious messages are difficult to assess because:
- warning signs are subtle
- spoofed branding looks convincing
- malicious requests often appear urgent
- users may not know what to verify
- security advice is often too technical or too late

Students, everyday users, and even early-career analysts can benefit from tools that make phishing indicators easier to interpret.

PhishTix was created to explore a better approach: a cybersecurity project that supports awareness, understanding, and structured message review without overwhelming the user.

This project is especially relevant in educational settings because it helps connect:
- theory to practice
- awareness to action
- user safety to analyst-style thinking
